# Insurance Prediction

## Project Overview
This project applies a binary-classification workflow to insurance data.

## Objective
Prepare insurance data, train a classification model, and evaluate the model using appropriate metrics.

## Tools
Python · Pandas · Scikit-learn · Jupyter Notebook

## Files
- `binary classification model.ipynb` — analysis and model development
- `insuarance.py` — prediction script
- `insurance_data.csv` — dataset
- `insurance.pkl` — saved model

## Important Cleanup
Rename `insuarance.py` to `insurance.py` to correct the spelling. Update any imports or documentation after renaming.

## Model Evaluation
Add real accuracy, precision, recall, F1-score, and confusion-matrix findings only if they are present in the notebook.

## How to Run
Clone the repository, install project dependencies, and open the notebook in Jupyter Notebook.
